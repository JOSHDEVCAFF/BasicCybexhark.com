HTML Font Tag Attributes

This page demonstrates the different attributes of the <font> tag.

1. Color Attribute
<font color="red">Red Text</font>
This text is red.
2. Size Attribute
<font size="6">Large Text</font>
This is large text.
3. Face Attribute
<font face="Georgia">Georgia Text</font>
This text uses the Georgia font.
4. Combining Attributes
<font face="Courier New" size="5" color="blue"> Hello World! </font>
Hello World!
