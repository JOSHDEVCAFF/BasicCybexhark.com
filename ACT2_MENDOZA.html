Activity No. 2

A Dream Within a Dream

by Edgar Allan Poe

About the Poem

This webpage demonstrates different HTML formatting tags and other important HTML tags.

HTML is used to structure and format content on a webpage.

Poem

Take this kiss upon the brow!
And, in parting from you now,
Thus much let me avow—
You are not wrong, who deem
That my days have been a dream;
Yet if hope has flown away
In a night, or in a day,
In a vision, or in none,
Is it therefore the less gone?

All that we see or seem
Is but a dream within a dream.

HTML Formatting Tags Demonstrated

  • <b> — Bold text
  • <strong> — Important text
  • <i> — Italic text
  • <em> — Emphasized text
  • <mark> — Highlighted text
  • <small> — Smaller text
  • <u> — Underlined text
  • <del> — Deleted text
  • <ins> — Inserted text
  • H2O — Subscript
  • x2 — Superscript

Other Important HTML Tags

  1. <html> — Defines the HTML document
  2. <head> — Contains document information
  3. <title> — Sets the browser tab title
  4. <body> — Contains visible webpage content
  5. <h1> - <h6> — Headings
  6. <p> — Paragraph
  7. <br> — Line break
  8. <hr> — Horizontal line
  9. <ul> and <ol> — Lists
  10. <li> — List item
  11. <section> — Groups related content
